# Changelog

## 0.1.0 - 2026-10-15

First release, tested on a real e-puck 1 (#2473) from Windows 10.

- asercom protocol over three interchangeable backends: real robot
  (Bluetooth serial), mock (no dependencies) and PyBullet twin (e-puck 1
  model and sensors from easabrain).
- Braitenberg controller from JSON; any controller class can be loaded.
- Commands: probe, baseline, run, drive, approach; CSV logs with metadata
  and figures; cross-platform launcher, bash scripts and Windows batch files.
- Calibration knobs: speed_scale, turn_scale, trim, ir_shift, ir_margin,
  ir_nsigma, ir_gain, ir_range, auto baseline, sim latency; robot profiles
  (calib/profile_2473_real.json, calib/profile_twin_2473.json).
- Escape timing in seconds, independent of the control rate.
- Docs: Bluetooth (Windows, macOS issue, Linux), firmware reload with Tiny
  Bootloader, calibration procedure with formulas, ground sensors, hardware
  log.
- README figures generated by scripts/make_readme_figures.py, with the
  approach measurements of robot 2473 in docs/data; CITATION.cff; GitHub
  Actions smoke tests.
